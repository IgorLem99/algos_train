Лестница из `n` ступенек, за один шаг можно подняться на 1 или 2 ступеньки. Сколькими различными способами можно добраться до вершины?

**Пример:** `n = 2` → `2` (1+1, 2); `n = 3` → `3` (1+1+1, 1+2, 2+1)

**Ограничения:** `1 ≤ n ≤ 45`

<details><summary>Подсказка</summary>dp[i] — число способов добраться до ступеньки i; на i можно прийти только с i−1 или i−2, поэтому dp[i] = dp[i−1] + dp[i−2].</details>

### Рекурсия с мемоизацией
`f(i)` — число способов дойти до ступеньки `i`: `f(i) = f(i−1) + f(i−2)`, `f(0) = f(1) = 1`. Без мемоизации дерево рекурсии экспоненциально, с кешем каждое состояние считается один раз.

**Сложность:** время O(n), память O(n).

```go
func climbStairs(n int) int {
	memo := make(map[int]int)
	var dfs func(i int) int
	dfs = func(i int) int {
		if i <= 1 {
			return 1
		}
		if v, ok := memo[i]; ok {
			return v
		}
		memo[i] = dfs(i-1) + dfs(i-2)
		return memo[i]
	}
	return dfs(n)
}
```

### Табличное DP (bottom-up)
Заполняем `dp[i] = dp[i−1] + dp[i−2]` слева направо от базы `dp[0] = dp[1] = 1`.

**Сложность:** время O(n), память O(n).

```go
func climbStairs(n int) int {
	dp := make([]int, n+1)
	dp[0], dp[1] = 1, 1
	for i := 2; i <= n; i++ {
		dp[i] = dp[i-1] + dp[i-2]
	}
	return dp[n]
}
```

### Две переменные
Переход смотрит только на два предыдущих значения, значит, вся таблица не нужна — это числа Фибоначчи.

**Сложность:** время O(n), память O(1).

```go
func climbStairs(n int) int {
	a, b := 1, 1 // dp[i-2], dp[i-1]
	for i := 2; i <= n; i++ {
		a, b = b, a+b
	}
	return b
}
```

Дан массив `cost`, где `cost[i]` — цена шага со ступеньки `i`. Заплатив, можно подняться на 1 или 2 ступеньки. Начать можно с индекса 0 или 1. Найди минимальную цену, чтобы оказаться выше последней ступеньки (на позиции `n`).

**Пример:** `cost = [10,15,20]` → `15`; `cost = [1,100,1,1,1,100,1,1,100,1]` → `6`

**Ограничения:** `2 ≤ n ≤ 1000`, `0 ≤ cost[i] ≤ 999`

<details><summary>Подсказка</summary>dp[i] — минимальная цена, чтобы встать на позицию i; dp[i] = min(dp[i−1] + cost[i−1], dp[i−2] + cost[i−2]), dp[0] = dp[1] = 0.</details>

### Рекурсия с мемоизацией
`f(i)` — минимальная цена дойти до позиции `i`. На `i` приходим с `i−1` (платим `cost[i−1]`) или с `i−2` (платим `cost[i−2]`); старт на 0 и 1 бесплатный.

**Сложность:** время O(n), память O(n).

```go
func minCostClimbingStairs(cost []int) int {
	n := len(cost)
	memo := make([]int, n+1)
	for i := range memo {
		memo[i] = -1
	}
	var dfs func(i int) int
	dfs = func(i int) int {
		if i <= 1 {
			return 0
		}
		if memo[i] < 0 {
			memo[i] = min(dfs(i-1)+cost[i-1], dfs(i-2)+cost[i-2])
		}
		return memo[i]
	}
	return dfs(n)
}
```

### Табличное DP
То же состояние `dp[i]`, считаем слева направо до `dp[n]`.

**Сложность:** время O(n), память O(n).

```go
func minCostClimbingStairs(cost []int) int {
	n := len(cost)
	dp := make([]int, n+1) // dp[0] = dp[1] = 0
	for i := 2; i <= n; i++ {
		dp[i] = min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])
	}
	return dp[n]
}
```

### Две переменные
Нужны только `dp[i−2]` и `dp[i−1]`.

**Сложность:** время O(n), память O(1).

```go
func minCostClimbingStairs(cost []int) int {
	a, b := 0, 0 // dp[i-2], dp[i-1]
	for i := 2; i <= len(cost); i++ {
		a, b = b, min(b+cost[i-1], a+cost[i-2])
	}
	return b
}
```

Дома стоят в ряд, в доме `i` лежит `nums[i]` денег. Нельзя грабить два соседних дома. Найди максимальную сумму.

**Пример:** `nums = [1,2,3,1]` → `4` (1 + 3); `nums = [2,7,9,3,1]` → `12` (2 + 9 + 1)

**Ограничения:** `1 ≤ n ≤ 100`, `0 ≤ nums[i] ≤ 400`

<details><summary>Подсказка</summary>dp[i] — максимум на первых i домах; дом i−1 либо пропускаем (dp[i−1]), либо берём (dp[i−2] + nums[i−1]).</details>

### Рекурсия с мемоизацией
`f(i)` — максимум, который можно унести с домов `i..n−1`: либо пропускаем дом (`f(i+1)`), либо грабим его и перепрыгиваем соседа (`nums[i] + f(i+2)`).

**Сложность:** время O(n), память O(n).

```go
func rob(nums []int) int {
	n := len(nums)
	memo := make([]int, n)
	for i := range memo {
		memo[i] = -1
	}
	var dfs func(i int) int
	dfs = func(i int) int {
		if i >= n {
			return 0
		}
		if memo[i] < 0 {
			memo[i] = max(dfs(i+1), nums[i]+dfs(i+2))
		}
		return memo[i]
	}
	return dfs(0)
}
```

### Табличное DP
`dp[i]` — максимум на префиксе из `i` домов: `dp[i] = max(dp[i−1], dp[i−2] + nums[i−1])`.

**Сложность:** время O(n), память O(n).

```go
func rob(nums []int) int {
	n := len(nums)
	dp := make([]int, n+1)
	dp[1] = nums[0]
	for i := 2; i <= n; i++ {
		dp[i] = max(dp[i-1], dp[i-2]+nums[i-1])
	}
	return dp[n]
}
```

### Две переменные
Храним только два последних значения таблицы.

**Сложность:** время O(n), память O(1).

```go
func rob(nums []int) int {
	prev, cur := 0, 0 // dp[i-2], dp[i-1]
	for _, x := range nums {
		prev, cur = cur, max(cur, prev+x)
	}
	return cur
}
```

То же, что House Robber, но дома стоят по кругу: первый и последний — соседи. Найди максимальную сумму без двух соседних домов.

**Пример:** `nums = [2,3,2]` → `3`; `nums = [1,2,3,1]` → `4`

**Ограничения:** `1 ≤ n ≤ 100`, `0 ≤ nums[i] ≤ 1000`

<details><summary>Подсказка</summary>Первый и последний дом вместе взять нельзя, поэтому ответ — максимум из линейной задачи на nums[0..n−2] и на nums[1..n−1]; внутри dp[i] — максимум на префиксе.</details>

### Две линейные задачи с мемоизацией
Разрываем круг: решаем House Robber на отрезке без последнего дома и на отрезке без первого. Внутри `f(i)` — максимум с домов `i..hi−1`, `f(i) = max(f(i+1), nums[i] + f(i+2))`. Отдельно случай одного дома.

**Сложность:** время O(n), память O(n).

```go
func rob(nums []int) int {
	n := len(nums)
	if n == 1 {
		return nums[0]
	}
	// максимум на полуинтервале домов [lo, hi)
	solve := func(lo, hi int) int {
		memo := make([]int, hi)
		for i := range memo {
			memo[i] = -1
		}
		var dfs func(i int) int
		dfs = func(i int) int {
			if i >= hi {
				return 0
			}
			if memo[i] < 0 {
				memo[i] = max(dfs(i+1), nums[i]+dfs(i+2))
			}
			return memo[i]
		}
		return dfs(lo)
	}
	return max(solve(0, n-1), solve(1, n))
}
```

### Две линейные задачи за O(1) памяти
Та же идея, но каждая линейная задача решается двумя переменными `dp[i−2]`, `dp[i−1]`.

**Сложность:** время O(n), память O(1).

```go
func rob(nums []int) int {
	n := len(nums)
	if n == 1 {
		return nums[0]
	}
	linear := func(a []int) int {
		prev, cur := 0, 0
		for _, x := range a {
			prev, cur = cur, max(cur, prev+x)
		}
		return cur
	}
	// без последнего дома или без первого
	return max(linear(nums[:n-1]), linear(nums[1:]))
}
```

Дана строка `s`. Верни её самую длинную подстроку-палиндром.

**Пример:** `s = "babad"` → `"bab"` (или `"aba"`); `s = "cbbd"` → `"bb"`

**Ограничения:** `1 ≤ n ≤ 1000`, только цифры и латинские буквы

<details><summary>Подсказка</summary>dp[i][j] — является ли s[i..j] палиндромом: s[i] == s[j] и dp[i+1][j−1]. Или расширяйся от каждого из 2n−1 центров.</details>

### Табличное DP
`dp[i][j]` — true, если `s[i..j]` палиндром. Переход: `s[i] == s[j]` и (длина ≤ 3 или `dp[i+1][j−1]`). Чтобы `dp[i+1][..]` был готов, идём по `i` справа налево.

**Сложность:** время O(n²), память O(n²).

```go
func longestPalindrome(s string) string {
	n := len(s)
	dp := make([][]bool, n)
	for i := range dp {
		dp[i] = make([]bool, n)
	}
	start, best := 0, 1
	for i := n - 1; i >= 0; i-- {
		for j := i; j < n; j++ {
			// края равны, а середина — палиндром (или её длина ≤ 1)
			if s[i] == s[j] && (j-i < 3 || dp[i+1][j-1]) {
				dp[i][j] = true
				if j-i+1 > best {
					start, best = i, j-i+1
				}
			}
		}
	}
	return s[start : start+best]
}
```

### Расширение от центра
У палиндрома есть центр: символ (нечётная длина) или промежуток между символами (чётная). Для каждого из `2n−1` центров расширяемся, пока края совпадают — по сути, это то же DP, но без таблицы. Существует и алгоритм Манакера за O(n), но на интервью обычно достаточно этого решения.

**Сложность:** время O(n²), память O(1).

```go
func longestPalindrome(s string) string {
	// возвращает полуинтервал [l, r) максимального палиндрома с центром (l, r)
	expand := func(l, r int) (int, int) {
		for l >= 0 && r < len(s) && s[l] == s[r] {
			l--
			r++
		}
		return l + 1, r
	}
	start, end := 0, 0
	for i := range s {
		if l, r := expand(i, i); r-l > end-start {
			start, end = l, r
		}
		if l, r := expand(i, i+1); r-l > end-start {
			start, end = l, r
		}
	}
	return s[start:end]
}
```

Дана строка `s`. Посчитай количество её подстрок-палиндромов (подстроки на разных позициях считаются разными).

**Пример:** `s = "abc"` → `3`; `s = "aaa"` → `6` (a, a, a, aa, aa, aaa)

**Ограничения:** `1 ≤ n ≤ 1000`, строчные латинские буквы

<details><summary>Подсказка</summary>dp[i][j] — палиндром ли s[i..j]; ответ — число true в таблице. Или расширение от 2n−1 центров: каждый успешный шаг — ещё один палиндром.</details>

### Табличное DP
`dp[i][j]` — true, если `s[i..j]` палиндром: `s[i] == s[j]` и (длина ≤ 3 или `dp[i+1][j−1]`). Считаем все true.

**Сложность:** время O(n²), память O(n²).

```go
func countSubstrings(s string) int {
	n := len(s)
	dp := make([][]bool, n)
	for i := range dp {
		dp[i] = make([]bool, n)
	}
	cnt := 0
	for i := n - 1; i >= 0; i-- {
		for j := i; j < n; j++ {
			if s[i] == s[j] && (j-i < 3 || dp[i+1][j-1]) {
				dp[i][j] = true
				cnt++
			}
		}
	}
	return cnt
}
```

### Расширение от центра
Центров `2n−1`: для номера `c` левый край `c/2`, правый `c/2 + c%2`. Расширяемся, пока края совпадают, и считаем каждый найденный палиндром. Манакер даёт O(n), но здесь не нужен.

**Сложность:** время O(n²), память O(1).

```go
func countSubstrings(s string) int {
	cnt := 0
	for c := 0; c < 2*len(s)-1; c++ {
		l, r := c/2, c/2+c%2 // чётный c — центр в символе, нечётный — между символами
		for l >= 0 && r < len(s) && s[l] == s[r] {
			cnt++
			l--
			r++
		}
	}
	return cnt
}
```

Буквы кодируются числами `'A' → "1"`, …, `'Z' → "26"`. Дана строка цифр `s`; посчитай число способов её декодировать. Коды с ведущим нулём (`"06"`) недопустимы.

**Пример:** `s = "12"` → `2` (AB, L); `s = "226"` → `3`; `s = "06"` → `0`

**Ограничения:** `1 ≤ n ≤ 100`, ответ помещается в 32-битное число

<details><summary>Подсказка</summary>dp[i] — число способов декодировать суффикс s[i:]; dp[i] = dp[i+1] (одна цифра, если не '0') + dp[i+2] (две цифры, если это 10..26).</details>

### Рекурсия с мемоизацией
`f(i)` — число декодирований `s[i:]`, `f(n) = 1`. Если `s[i] == '0'` — 0 способов. Иначе берём одну цифру (`f(i+1)`) и, если `s[i..i+1]` в диапазоне 10..26, ещё и две (`f(i+2)`).

**Сложность:** время O(n), память O(n).

```go
func numDecodings(s string) int {
	n := len(s)
	memo := make([]int, n+1)
	for i := range memo {
		memo[i] = -1
	}
	var dfs func(i int) int
	dfs = func(i int) int {
		if i == n {
			return 1
		}
		if s[i] == '0' {
			return 0
		}
		if memo[i] >= 0 {
			return memo[i]
		}
		res := dfs(i + 1)
		if i+1 < n && (s[i] == '1' || (s[i] == '2' && s[i+1] <= '6')) {
			res += dfs(i + 2)
		}
		memo[i] = res
		return res
	}
	return dfs(0)
}
```

### Табличное DP
Тот же переход, но массив `dp` заполняется справа налево от базы `dp[n] = 1`.

**Сложность:** время O(n), память O(n).

```go
func numDecodings(s string) int {
	n := len(s)
	dp := make([]int, n+1)
	dp[n] = 1
	for i := n - 1; i >= 0; i-- {
		if s[i] == '0' {
			continue // dp[i] = 0
		}
		dp[i] = dp[i+1]
		if i+1 < n && (s[i] == '1' || (s[i] == '2' && s[i+1] <= '6')) {
			dp[i] += dp[i+2]
		}
	}
	return dp[0]
}
```

### Две переменные
`dp[i]` зависит только от `dp[i+1]` и `dp[i+2]`.

**Сложность:** время O(n), память O(1).

```go
func numDecodings(s string) int {
	n := len(s)
	one, two := 1, 0 // dp[i+1], dp[i+2]
	for i := n - 1; i >= 0; i-- {
		cur := 0
		if s[i] != '0' {
			cur = one
			if i+1 < n && (s[i] == '1' || (s[i] == '2' && s[i+1] <= '6')) {
				cur += two
			}
		}
		one, two = cur, one
	}
	return one
}
```

Даны номиналы монет `coins` (каждой — неограниченно) и сумма `amount`. Найди минимальное число монет, дающее ровно `amount`, или `-1`, если это невозможно.

**Пример:** `coins = [1,2,5], amount = 11` → `3` (5 + 5 + 1); `coins = [2], amount = 3` → `-1`

**Ограничения:** `1 ≤ len(coins) ≤ 12`, `1 ≤ coins[i] ≤ 2³¹−1`, `0 ≤ amount ≤ 10⁴`

<details><summary>Подсказка</summary>dp[a] — минимум монет для суммы a; dp[a] = 1 + min по монетам c ≤ a от dp[a−c]. Жадность не работает: [1,3,4], 6 → 3+3, а не 4+1+1.</details>

### Рекурсия с мемоизацией
`f(a)` — минимум монет для суммы `a`, `f(0) = 0`. Перебираем последнюю монету `c`: `f(a) = 1 + min f(a−c)`. Недостижимость кодируем как `-1`.

**Сложность:** время O(amount · k), память O(amount), где k — число номиналов.

```go
func coinChange(coins []int, amount int) int {
	memo := make([]int, amount+1)
	for i := range memo {
		memo[i] = -2 // -2 — ещё не посчитано, -1 — недостижимо
	}
	var dfs func(a int) int
	dfs = func(a int) int {
		if a == 0 {
			return 0
		}
		if memo[a] != -2 {
			return memo[a]
		}
		best := -1
		for _, c := range coins {
			if c <= a {
				if r := dfs(a - c); r >= 0 && (best < 0 || r+1 < best) {
					best = r + 1
				}
			}
		}
		memo[a] = best
		return best
	}
	return dfs(amount)
}
```

### Табличное DP (неограниченный рюкзак)
Заполняем `dp[a]` по возрастанию `a`. В качестве «бесконечности» берём `amount + 1` — монет никогда не нужно больше, чем `amount`.

**Сложность:** время O(amount · k), память O(amount).

```go
func coinChange(coins []int, amount int) int {
	inf := amount + 1
	dp := make([]int, amount+1)
	for a := 1; a <= amount; a++ {
		dp[a] = inf
		for _, c := range coins {
			if c <= a {
				dp[a] = min(dp[a], dp[a-c]+1)
			}
		}
	}
	if dp[amount] > amount {
		return -1
	}
	return dp[amount]
}
```

Дан массив целых чисел `nums`. Найди непустой непрерывный подмассив с максимальным произведением и верни это произведение.

**Пример:** `nums = [2,3,-2,4]` → `6`; `nums = [-2,0,-1]` → `0`

**Ограничения:** `1 ≤ n ≤ 2·10⁴`, `−10 ≤ nums[i] ≤ 10`, произведение любого подмассива помещается в 32 бита

<details><summary>Подсказка</summary>Храни два состояния: hi[i] и lo[i] — максимальное и минимальное произведение подмассива, оканчивающегося в i. Отрицательное число превращает минимум в максимум.</details>

### DP по максимуму и минимуму
`hi` и `lo` — максимальное и минимальное произведение подмассива, заканчивающегося на текущем элементе `x`. Переход: `hi = max(x, hi·x, lo·x)`, `lo = min(x, hi·x, lo·x)` (по старым значениям). Ответ — максимум `hi` по всем позициям. Это вариация алгоритма Кадане.

**Сложность:** время O(n), память O(1).

```go
func maxProduct(nums []int) int {
	res, hi, lo := nums[0], nums[0], nums[0]
	for _, x := range nums[1:] {
		// умножение на отрицательное меняет max и min местами;
		// параллельное присваивание использует старые hi и lo
		hi, lo = max(x, hi*x, lo*x), min(x, hi*x, lo*x)
		res = max(res, hi)
	}
	return res
}
```

### Префиксные и суффиксные произведения
Без нулей оптимальный подмассив — это префикс или суффикс: если отрицательных чисел нечётное количество, выкидываем всё до первого или после последнего из них. Нули разбивают массив на куски, поэтому, встретив 0, начинаем произведение заново.

**Сложность:** время O(n), память O(1).

```go
func maxProduct(nums []int) int {
	n := len(nums)
	res := nums[0]
	pre, suf := 1, 1
	for i := 0; i < n; i++ {
		if pre == 0 {
			pre = 1
		}
		if suf == 0 {
			suf = 1
		}
		pre *= nums[i]
		suf *= nums[n-1-i]
		res = max(res, pre, suf)
	}
	return res
}
```

Дана строка `s` и словарь `wordDict`. Можно ли разбить `s` на последовательность слов из словаря (слова можно использовать многократно)?

**Пример:** `s = "leetcode", wordDict = ["leet","code"]` → `true`; `s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]` → `false`

**Ограничения:** `1 ≤ len(s) ≤ 300`, `1 ≤ len(wordDict) ≤ 1000`, `1 ≤ len(word) ≤ 20`

<details><summary>Подсказка</summary>dp[i] — можно ли разбить префикс s[:i]; dp[i] = true, если есть слово w, которым заканчивается s[:i], и dp[i − len(w)] = true.</details>

### Рекурсия с мемоизацией
`f(i)` — можно ли разбить суффикс `s[i:]`. Пробуем каждое слово как префикс суффикса: `f(i) = OR f(i + len(w))`. Кеш по `i` превращает экспоненциальный перебор в полиномиальный.

**Сложность:** время O(n · m · L), память O(n), где m — размер словаря, L — длина слова.

```go
func wordBreak(s string, wordDict []string) bool {
	memo := make(map[int]bool)
	var dfs func(i int) bool
	dfs = func(i int) bool {
		if i == len(s) {
			return true
		}
		if v, ok := memo[i]; ok {
			return v
		}
		for _, w := range wordDict {
			if strings.HasPrefix(s[i:], w) && dfs(i+len(w)) {
				memo[i] = true
				return true
			}
		}
		memo[i] = false
		return false
	}
	return dfs(0)
}
```

### Табличное DP
`dp[i]` — можно ли разбить префикс `s[:i]`, `dp[0] = true`. Для каждого `i` проверяем, оканчивается ли префикс каким-нибудь словом `w` с `dp[i − len(w)] = true`.

**Сложность:** время O(n · m · L), память O(n).

```go
func wordBreak(s string, wordDict []string) bool {
	n := len(s)
	dp := make([]bool, n+1)
	dp[0] = true
	for i := 1; i <= n; i++ {
		for _, w := range wordDict {
			if k := len(w); k <= i && dp[i-k] && s[i-k:i] == w {
				dp[i] = true
				break
			}
		}
	}
	return dp[n]
}
```

Дан массив `nums`. Найди длину самой длинной строго возрастающей подпоследовательности (не обязательно непрерывной).

**Пример:** `nums = [10,9,2,5,3,7,101,18]` → `4` (2, 3, 7, 101); `nums = [7,7,7,7]` → `1`

**Ограничения:** `1 ≤ n ≤ 2500`, `−10⁴ ≤ nums[i] ≤ 10⁴`

<details><summary>Подсказка</summary>dp[i] — длина LIS, оканчивающейся на nums[i]: 1 + max dp[j] по j < i с nums[j] < nums[i]. Для O(n log n) храни tails[k] — минимальный хвост LIS длины k+1.</details>

### Рекурсия с мемоизацией
`f(i)` — длина LIS, которая начинается с `nums[i]`: `f(i) = 1 + max f(j)` по `j > i` с `nums[j] > nums[i]`. Ответ — максимум `f(i)`.

**Сложность:** время O(n²), память O(n).

```go
func lengthOfLIS(nums []int) int {
	n := len(nums)
	memo := make([]int, n) // 0 — ещё не посчитано (сам ответ всегда ≥ 1)
	var dfs func(i int) int
	dfs = func(i int) int {
		if memo[i] > 0 {
			return memo[i]
		}
		best := 1
		for j := i + 1; j < n; j++ {
			if nums[j] > nums[i] {
				best = max(best, 1+dfs(j))
			}
		}
		memo[i] = best
		return best
	}
	res := 0
	for i := range nums {
		res = max(res, dfs(i))
	}
	return res
}
```

### Табличное DP за O(n²)
`dp[i]` — длина LIS, оканчивающейся на `nums[i]`: `dp[i] = 1 + max dp[j]` по `j < i` с `nums[j] < nums[i]`.

**Сложность:** время O(n²), память O(n).

```go
func lengthOfLIS(nums []int) int {
	dp := make([]int, len(nums))
	res := 0
	for i := range nums {
		dp[i] = 1
		for j := 0; j < i; j++ {
			if nums[j] < nums[i] {
				dp[i] = max(dp[i], dp[j]+1)
			}
		}
		res = max(res, dp[i])
	}
	return res
}
```

### Patience sorting + бинарный поиск
`tails[k]` — минимальный возможный последний элемент возрастающей подпоследовательности длины `k+1`; массив `tails` всегда отсортирован. Для каждого `x` бинарным поиском находим первый `tails[k] ≥ x` и заменяем его на `x` (или дописываем в конец). Длина `tails` — ответ (но сам `tails` не обязательно является LIS).

**Сложность:** время O(n log n), память O(n).

```go
func lengthOfLIS(nums []int) int {
	tails := []int{}
	for _, x := range nums {
		k := sort.SearchInts(tails, x) // первая позиция с tails[k] >= x
		if k == len(tails) {
			tails = append(tails, x)
		} else {
			tails[k] = x // тот же размер, но хвост меньше — лучше для будущего
		}
	}
	return len(tails)
}
```

Дан массив положительных чисел `nums`. Можно ли разбить его на два подмножества с равными суммами?

**Пример:** `nums = [1,5,11,5]` → `true` ([1,5,5] и [11]); `nums = [1,2,3,5]` → `false`

**Ограничения:** `1 ≤ n ≤ 200`, `1 ≤ nums[i] ≤ 100`

<details><summary>Подсказка</summary>Нужно подмножество с суммой total/2 — это рюкзак 0/1. dp[s] — достижима ли сумма s; для каждого x идём по s сверху вниз: dp[s] |= dp[s−x].</details>

### Рекурсия с мемоизацией
Если сумма нечётна — сразу `false`. Иначе `f(i, t)` — можно ли набрать сумму `t` из `nums[i:]`: берём `nums[i]` (`f(i+1, t−nums[i])`) или пропускаем (`f(i+1, t)`).

**Сложность:** время O(n · S), память O(n · S), где S = total/2.

```go
func canPartition(nums []int) bool {
	total := 0
	for _, x := range nums {
		total += x
	}
	if total%2 == 1 {
		return false
	}
	target := total / 2
	memo := make([][]int8, len(nums)) // 0 — не посчитано, 1 — true, 2 — false
	for i := range memo {
		memo[i] = make([]int8, target+1)
	}
	var dfs func(i, t int) bool
	dfs = func(i, t int) bool {
		if t == 0 {
			return true
		}
		if i == len(nums) || t < 0 {
			return false
		}
		if memo[i][t] != 0 {
			return memo[i][t] == 1
		}
		ok := dfs(i+1, t-nums[i]) || dfs(i+1, t)
		memo[i][t] = 2
		if ok {
			memo[i][t] = 1
		}
		return ok
	}
	return dfs(0, target)
}
```

### Рюкзак 0/1 в одномерном массиве
`dp[s]` — достижима ли сумма `s` уже рассмотренными числами, `dp[0] = true`. Для каждого `x`: `dp[s] = dp[s] || dp[s−x]`. Идём по `s` сверху вниз, чтобы каждое число использовалось не больше одного раза.

**Сложность:** время O(n · S), память O(S).

```go
func canPartition(nums []int) bool {
	total := 0
	for _, x := range nums {
		total += x
	}
	if total%2 == 1 {
		return false
	}
	target := total / 2
	dp := make([]bool, target+1)
	dp[0] = true
	for _, x := range nums {
		// сверху вниз: dp[s-x] ещё «старый», без текущего x
		for s := target; s >= x; s-- {
			dp[s] = dp[s] || dp[s-x]
		}
	}
	return dp[target]
}
```
