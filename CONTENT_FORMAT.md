# Формат контента AlgoTrain

Весь контент — обычные Markdown-файлы. Если сервер запущен рядом с папкой `content/`, он подхватывает изменения
файлов на лету. Иначе используется копия, встроенная в бинарник при сборке.

```
content/
  problems/
    neetcode150/01-arrays-hashing.md   ← несколько задач в одном файле
    <любая-папка>/<файл>.md            ← свои списки (blind75, yandex, ...)
  algorithms/<id>.md                   ← статья об алгоритме
  judge/<файл>.md                      ← заготовки кода и тесты для тренажёра, см. JUDGE_FORMAT.md
```

Задачи, добавленные через интерфейс («Добавить задачу», только администратор), хранятся в БД, а не в файлах.

Проверки:

```
go run . -check              # все Go-решения компилируются
go run . -check two-sum      # только задачи с id, начинающимся на префикс
go run . -check-judge        # эталонные решения проходят тесты из content/judge
```

## Задача

Файл может содержать много задач подряд. Каждая начинается с блока метаданных между строками `---`.

```markdown
---
id: two-sum
title: Two Sum
difficulty: Easy
category: Arrays & Hashing
leetcode: 1
lists: neetcode150, blind75
algorithms: hashing
order: 3
---
Дан массив целых чисел `nums` и число `target`. Верни индексы двух чисел, сумма которых равна `target`.
Ровно одно решение; один элемент нельзя использовать дважды.

**Пример:** `nums = [2,7,11,15], target = 9` → `[0,1]`

**Ограничения:** `2 ≤ n ≤ 10⁴`

<details><summary>Подсказка</summary>Для каждого x нужно быстро узнать, встречалось ли target − x.</details>

### Перебор всех пар
Проверяем каждую пару (i, j).

**Сложность:** время O(n²), память O(1).

```go
func twoSum(nums []int, target int) []int {
	for i := range nums {
		for j := i + 1; j < len(nums); j++ {
			if nums[i]+nums[j] == target {
				return []int{i, j}
			}
		}
	}
	return nil
}
```

### Хеш-таблица за один проход
Храним `значение → индекс` уже просмотренных чисел и ищем дополнение `target − x`.

**Сложность:** время O(n), память O(n).

```go
func twoSum(nums []int, target int) []int {
	seen := make(map[int]int, len(nums))
	for i, x := range nums {
		if j, ok := seen[target-x]; ok {
			return []int{j, i}
		}
		seen[x] = i
	}
	return nil
}
```
```

Правила:

- Метаданные: `id` (slug LeetCode, если это задача с LeetCode — тогда ссылка строится автоматически), `title`, `difficulty` (Easy/Medium/Hard), `category`, `leetcode` (номер), `lists` (через запятую), `algorithms` (id статей из `content/algorithms`, через запятую), `order` (порядок в списке), необязательно `url`.
- Всё до первого заголовка `### ` — условие задачи. Каждый `### Заголовок` — отдельное решение: пояснение + один блок ```go.
- Решения пишутся в стиле LeetCode: **без** `package` и `import`. Импорты стандартной библиотеки проверка подставит сама. Типы `ListNode {Val int; Next *ListNode}` и `TreeNode {Val int; Left, Right *TreeNode}` объявлять **не нужно**. Любые другие типы (`Node` для Clone Graph, структуры для design-задач) объявляются в самом блоке.
- Строка `---` внутри кода не считается разделителем.
- Сырой HTML (например `<details>`) должен быть одним блоком без пустых строк внутри.

- `<div data-viz="имя"></div>` вставляет пошаговую интерактивную визуализацию из `web/viz.js` (отдельной строкой, с пустыми строками вокруг).
