# AlgoTrain

Тренажёр алгоритмов для Go-разработчика:

- NeetCode 150;
- интервальное повторение с календарём;
- встроенный редактор кода с автоматической проверкой решений на тестах;
- эталонные решения на Go;
- статьи об алгоритмах с пошаговой интерактивной инфографикой.

Пользователи регистрируются, и их прогресс, черновики и история отправок хранятся на сервере.

## Локальный запуск

```
go run .
```

Открыть http://127.0.0.1:7341 и зарегистрироваться. Нужен Go ≥ 1.22: более новый toolchain скачается сам.
Данные хранятся в SQLite (`data/algotrain.db`), внешние сервисы не нужны.

Флаги:

- `-addr 127.0.0.1:9000` — другой адрес;
- `-root путь` — корень проекта;
- `-db postgres://…` — использовать PostgreSQL.

Если рядом лежат папки `content/` и `web/`, они читаются с диска, и правки видны без перезапуска.
Иначе используется копия, встроенная в бинарник.

Локально код решений запускается без песочницы, прямо на вашей машине. В интернет сервис выкладывается через
Docker Compose: HTTPS, PostgreSQL, несколько копий приложения и изолированный раннер кода. Инструкция в [DEPLOY.md](DEPLOY.md).

## Что внутри

- **Сегодня** — задачи на повторение (просроченные сверху), кнопки «Вспомнил / Забыл», график нагрузки на 21 день по этапам, лестница повторений, прогресс по темам, тепловая карта активности за год.
- **Задачи** — NeetCode 150 по темам (как roadmap), фильтры по списку, сложности, статусу и алгоритму. Галочка — «решил сегодня».
- **Задача** — условие, подсказка, 2–3 эталонных решения на Go (скрыты, пока не нажмёшь), свои заметки, график повторения задачи, ссылки на статьи об алгоритмах, похожие задачи, история.
- **⌨ Решать** — редактор кода рядом с условием:
  - подсветка Go, номера строк, автоотступы и автозакрытие скобок, комментирование строк;
  - **Запустить** (Ctrl+') — прогон на первых примерах;
  - **Отправить** (Ctrl+Enter) — прогон на всех тестах с записью в историю;
  - для каждого теста видно вход, ожидаемый и полученный ответ и вывод `fmt.Println`;
  - ошибки компиляции и паники подсвечиваются в строках кода, а таймауты, переполнение стека и превышение памяти распознаются отдельно;
  - черновик сохраняется автоматически, на сервере и в браузере.
- **Мои отправки** — история всех решений со статусом, временем и кодом. По каждой задаче видна своя история.
- **Календарь** — месяц с запланированными повторениями (цвет = этап, полупрозрачные — прогноз) и сделанным; клик по дню — список с кнопками.
- **Алгоритмы** — статьи: суть, история, как работает (интерактивная визуализация + схема), шаблон на Go, сложность, когда применять, применение в бигтехе / финтехе / геймдеве, типичные ошибки.
- **Добавить задачу** (только администратор) — форма с условием, решениями, заготовкой кода и тестами. Задача сохраняется в БД.
- **Настройки** — имя, смена пароля, выход на других устройствах, интервалы повторения, экспорт и импорт прогресса в JSON.

## Интервальное повторение

После первого решения задачи в день D повторения назначаются на **D+1, D+3, D+6, D+11** (меняется в настройках).

- «Вспомнил» — переход на следующий этап. Если повторение сделано с опозданием, следующие этапы сдвигаются, сохраняя промежутки между ними (1 → 2 → 3 → 5 дней).
- «Не вспомнил» — цикл начинается заново от сегодняшнего дня.
- Все этапы пройдены — задача «выучена».

Принятая отправка в тренажёре предлагает сразу отметить задачу решённой или повторённой.

## Данные

- Аккаунты, прогресс, черновики и история отправок хранятся в БД: SQLite локально, PostgreSQL в продакшене.
  Прогресс из старой версии (`data/progress.json`) можно перенести через «Настройки → Импорт».
- Контент — Markdown в `content/`. Формат задач и статей описан в [CONTENT_FORMAT.md](CONTENT_FORMAT.md), формат тестов —
  в [JUDGE_FORMAT.md](JUDGE_FORMAT.md).

Проверки контента:

```
go run . -check                # все эталонные решения компилируются
go run . -check-judge          # эталонные решения проходят тесты, а заготовки компилируются
go run . -check-judge two-sum  # только задачи с id, начинающимся на префикс
```

Нагрузочный тест работающего сервера:

```
go run ./cmd/loadtest -url http://127.0.0.1:7341 -users 10 -workers 100 -runners 5 -d 30s
```

## Добавить свой список задач

Создай папку `content/problems/<список>/` и файлы `.md` в формате из `CONTENT_FORMAT.md`, в `lists:` укажи имя списка — он появится в фильтре.
Тесты для тренажёра — файл в `content/judge/` (см. `JUDGE_FORMAT.md`).
