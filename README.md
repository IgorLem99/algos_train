# AlgoTrain

Локальный тренажёр алгоритмов для Go-разработчика: NeetCode 150, интервальное повторение с календарём, эталонные решения на Go и статьи об алгоритмах с пошаговой интерактивной инфографикой.

## Запуск

```
go run .
```

Открыть http://127.0.0.1:7341. Нужен только Go ≥ 1.22, без внешних зависимостей.

Флаги: `-addr 127.0.0.1:9000` — другой адрес, `-root путь` — другой корень проекта.

## Что внутри

- **Сегодня** — задачи на повторение (просроченные сверху), кнопки «Вспомнил / Забыл», график нагрузки на 21 день по этапам, лестница повторений, прогресс по темам, тепловая карта активности за год.
- **Задачи** — NeetCode 150 по темам (как roadmap), фильтры по списку, сложности, статусу и алгоритму. Галочка — «решил сегодня».
- **Задача** — условие, подсказка, 2–3 эталонных решения на Go (скрыты, пока не нажмёшь), свои заметки, график повторения задачи, ссылки на статьи об алгоритмах, похожие задачи, история.
- **Календарь** — месяц с запланированными повторениями (цвет = этап, полупрозрачные — прогноз) и сделанным; клик по дню — список с кнопками.
- **Алгоритмы** — статьи: суть, история, как работает (интерактивная визуализация + схема), шаблон на Go, сложность, когда применять, применение в бигтехе / финтехе / геймдеве, типичные ошибки.
- **Добавить задачу** — форма, сохраняет `content/problems/custom/<id>.md`.

## Интервальное повторение

После первого решения задачи в день D повторения назначаются на **D+1, D+3, D+6, D+11** (меняется в настройках).

- «Вспомнил» — переход на следующий этап. Если повторение сделано с опозданием, следующие этапы сдвигаются, сохраняя промежутки между ними (1 → 2 → 3 → 5 дней).
- «Не вспомнил» — цикл начинается заново от сегодняшнего дня.
- Все этапы пройдены — задача «выучена».

## Данные

- Прогресс — `data/progress.json` (резервная копия раз в день — `data/backup/`). Экспорт/импорт — в настройках.
- Контент — Markdown в `content/`, перечитывается при каждом обновлении страницы. Формат описан в [CONTENT_FORMAT.md](CONTENT_FORMAT.md).

Проверить, что все эталонные решения компилируются:

```
go run . -check
```

## Добавить свой список задач

Создай папку `content/problems/<список>/` и файлы `.md` в формате из `CONTENT_FORMAT.md`, в `lists:` укажи имя списка — он появится в фильтре.
